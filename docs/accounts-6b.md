# 6b：账号验收（ai-chat，未发布）

本批只有账号和本机隔离，没有上传、下载或认领记录。未登录的数据库和草稿原样保留；登录后使用独立的数据库和带账号后缀的本机设置。已登录设备离线时可以打开上次使用的本机账号；角色和服务端权限仍由 Worker 验证。保留记录退出不等于清空设备，不适合把浏览器配置文件交给不信任的人。

## 设备端和服务端各保存什么

- 密码仅用于设备端 PBKDF2-SHA256（600,000 次，16 字节随机盐）；HKDF 使用不同用途标记派生登录凭证和包裹密钥。AES-GCM 每次包裹使用新的 12 字节 IV。改密、恢复都只重包同一对数据钥匙。
- 恢复码从 16 字节真随机数生成。22 个编码字符保留全部 128 位，附加两个校验字符，按六组四个显示，区分大小写。注册成功先显示抄写确认，确认后才创建会话。
- 登录设备的 IndexedDB 保存不可导出的 AES 和 HMAC CryptoKey。导出仍只遍历原六个正式数据集合，不会遍历钥匙仓库。D1 保存验证凭证的 HMAC、盐、两份包裹后的钥匙；会话、重置令牌、邀请码只存哈希。
- 会话 Cookie 的有效期为 180 天；使用满一小时才更新最近使用时间并续期。重置令牌十分钟有效，一次用完；修改密码撤销其他会话，恢复或停用撤销全部旧会话。
- `AUTH_PEPPER` 不能随意替换，否则现有账号的登录与恢复凭证均无法直接验证。

## 本机验收

`npm run test:worker` 与 `npm run test:ui`；浏览器流程为 `node tools/check-accounts.cjs`，使用本地 Wrangler/D1、独立 Chrome 配置与临时账号。可指定 `WRANGLER_JS`、`PLAYWRIGHT_PATH`、`CHROME_PATH`、`QA_OUTPUT`。不调用模型，不连接生产数据库。脚本只报告状态、数量、耗时。

| 场景 | 检查 |
| --- | --- |
| 管理员和普通账号 | 初始口令仅可创建首个管理员；邀请码注册、抄写确认、一次性使用；撤销和过期后不能再注册 |
| AI 权限 | 管理员凭 Cookie 可访问健康检查；普通账号看不到聊天标签或 AI 设置，调用聊天及管理接口均为 403；普通会话附带旧口令也不会获得管理员权限 |
| 锁定 | 同一用户名第 5 次错误返回 429，界面提示 15 分钟；独立测试验证来自同一 IP 的不同用户名共 20 次错误触发 1 小时锁定 |
| 会话和恢复 | 改密后其他设备 401；新浏览器配置用新密码登录；恢复后旧密码失效，原数据钥匙仍可用。检测过期及重复使用重置令牌，以及会话续期和过期 |
| 隔离与管理 | 同一浏览器切换账号，正式记录、聊天和偏好隔离；有未上传记录时阻止清除。停用即时拒绝原会话，重新启用不会复活它。可改配额；删除需要输入正确用户名 |
| 数据检查 | 虚构 D1 中的验证摘要 32 字节，包裹后的钥匙各 92 字节；未发现原始密码、原始登录凭证、恢复码或会话令牌。管理接口只返回元数据和占用统计 |
| 手机性能 | 本机未连接实体手机。请在目标手机浏览器中打开 `tools/pbkdf2-mobile.html` 测三次，记录机型和耗时；低端机超 3 秒时保持 600,000 次不变，等用户决定 |

本次本机结果：51 项自动测试通过，浏览器完成 8 组集成验收；桌面 Chrome 两次派生为 219 和 181 毫秒（不是手机数据）。index.html 为 350,384 字节，gzip 109,117 字节。

管理员管理页显示 D1 实际数据库大小，400 MB 以上标红。500 MB 是 [D1 免费版单库上限](https://developers.cloudflare.com/d1/platform/limits/)。6b 无云端记录时条数和大小为零。
