# 第 5 批：AI 页面（v6.11）

日期：2026-11-13。分支：`codex/batch5-ai-wip`。本批停在截图验收，未合并主分支、未部署新页面、未改错主节点。

## 已实现

- 复盘主卡片下方 56px 入口，显示总结/探索状态；空白日期隐藏，离线时置灰。
- 独立 AI 页绑定进入日期，隐藏底部导航；总结、探索之间切换保留内容。
- 页内输入访问口令，调用 health 验证；401 后补入口令可以继续原操作。
- 总结流式输出、停止、重新生成；重新生成完整成功前保留旧总结。复盘卡片只读显示最多六行。
- 探索起步问题、多轮对话、自动草稿、刷新恢复、显式保存、新一轮前提示、只读历史与删除。
- 总结和探索共用材料清单。首次发送、材料/勾选变化时确认；探索开始后固定该轮材料。
- 设置页包含修改口令、测试连接、模型显示，以及默认折叠的诊断信息。
- 诊断只保存在内存：接口、状态、耗时、结束事件、三项 token 计数、主/备、是否跳转、跳转域名。刷新清空，不导出、不同步。
- Worker 诊断头只返回节点标记与域名；不含 URL 路径、查询参数、密钥或内容。
