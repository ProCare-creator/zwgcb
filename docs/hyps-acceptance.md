# 从探索提炼假设 · 小批次验收

日期：2026-11-14。分支：ai-chat。第 A 批已按用户意见验收通过，不做补测。未开始第 B 批；本批不合并 main、不部署，应用和 Service Worker 版本仍为 v6.11.1。

## 已实现

- 当前探索至少有两条 Claude 回复时，在“保存这次探索”旁显示“提炼假设”；已保存对话也有入口。
- 发送前复用现有确认框，可查看这次对话全文和现有假设编号、文字。取消不会调用模型。
- `/api/hyps` 复用身份、Origin、限流和请求上限，使用总结模型、medium、4000 tokens，非流式返回最多三条建议；只有用户消息可作为依据。
- 卡片显示文字、依据和相近编号。加入前可编辑，确认后调用原有 makeHyp / put，以原有规则分配编号、设为待验证。模型的依据不会自动写成支持证据。
- 新假设有可选 src；点击“已加入 #编号”定位假设，点击“来自 11/13 的对话”回到原有历史区域里的对应对话。
- 如果来源对话尚未保存，确认加入时同时保存这一轮，保持当前探索；编辑确认处说明了这个行为。仅提炼、查看、取消编辑不会写记录或增加编号。
- 提炼结果、相近提示和编辑状态仅存在内存，刷新清空；已加入的假设及来源正常持久化。失败可重试，双击确认不会重复新增。
