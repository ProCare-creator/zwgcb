# v6.12.1 本机验收

基线：生产提交 `f07610c`。本批不包含 IndexedDB 迁移。

- 本机 Chrome 用确认框选择一天的虚构记录，发出第一条消息后刷新，再连续发送两条未选材料的消息。三次浏览器请求分别有 1、3、5 条消息；每次都有同一份快照。模拟上游收到的每个请求均恰有一个材料块，在第一条用户正文前。假设清单只出现在最后一条用户正文前；系统和该正文带缓存标记。
- 自动检查覆盖旧消息只有日期、旧客户端顶层附件、材料转义、材料计入 256 KiB、导入字段安全显示，以及草稿最终写入。模拟 2.6 秒生成期间在 1.0、2.0 秒写草稿，结束时在 2.6 秒写入最后的正文。
- 两次真实请求由本机 Wrangler 转发到项目的主中转节点。仅在诊断用的本机入口将同一段 8,251 字的虚构材料附在系统提示末尾，两次请求正文一致，发起时间相隔 7.036 秒。

| 请求 | input_tokens | cache_creation_input_tokens | cache_read_input_tokens |
| --- | ---: | ---: | ---: |
| 第一次 | 0 | 11,621 | 0 |
| 第二次 | 0 | 1,920 | 9,701 |

第二次有缓存读取；上述数字是中转节点的实际回报，不代表每次请求都会命中。测试共 45 项通过。构建单文件为 328,324 字节，gzip 101,098 字节。
