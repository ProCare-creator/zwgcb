# 6c 按账号云端存储验收

2026-11-22，在 `cloud-sync` 的 `01f77fe` 上继续。测试使用本机 Wrangler、独立 D1、390 × 844 的 Chrome 窗口及虚构账号。每台测试设备使用单独的浏览器存储。生产网络和手机耗时待用户验收。

## 功能核对

| 场景 | 实测结果 |
| --- | --- |
| 首次认领并换设备 | 认领 1 条日期记录、1 条聊天、1 条备忘录。第二台设备登录同一账号后，从导出文件核对了三种记录。草稿复制到原设备的账号专属存储。 |
| 暂不认领、重复认领、30 天清理 | 暂不认领后退出仍能看到原记录；确认认领后换账号，认领提示为 0 次。将测试副本的保留期设为到期，重新打开后原件清除，之后新增的记录仍在。 |
| 两台设备离线写入 | 分别新增的两条备忘录合并成功；同一条备忘录的两次编辑以时间较新的一份为准。 |
| 冲突历史 | 让较新的编辑先上云，较旧编辑留在离线设备。模拟上传历史中断后刷新，在下载的加密备份中用设备钥匙解开该历史版本，核对集合、文档 ID 和原文。 |
| 删除传播 | 把两台测试设备的编辑和删除固定在同一毫秒，编辑先到云端，再同步删除。两台设备导出时该条均消失。旧提交在此项会恢复已删除记录。 |
| 密码与会话 | 改密后另一设备拉取返回 401。输入旧密码时，账号本机库的记录键与内容指纹一致，云端序号变化为 0。新密码可解开原记录，停止同步后用当前密码重新开启成功。 |
| 账号隔离 | 单元测试和浏览器检查使用两个账号。读取结果按会话所属账号返回；带其他账号标识的写入仍归当前会话，另一个账号的版本、序号和内容保持独立。 |
| 配额与用量 | 配额降到 1 字节后，上传返回 413，本机新增的记录仍可导出。恢复配额后上传成功。覆盖、冲突历史和历史清理都纳入字节统计，整批超限回滚。已超额账号仍可同步删除。 |
| D1 与管理页 | 抽查测试账号的有效记录，键均为 43 位编码，密文中未检出测试用中文。管理页的有效条数与 D1 一致，占用字节与备份中当前及历史密文大小之和一致。 |
| 备份期间有改动 | 在读取备份期间新增历史并同时清理旧历史，即使条数、大小都相同，下载也会中断。重试后成功读取一致的备份。 |

## 容量与构建

最终一轮使用 2,990 条备忘录和 10 条聊天，聊天正文合计 10,485,760 字节。恢复后逐条核对了备忘录文字及聊天正文。

| 测量项 | 本机结果 |
| --- | ---: |
| 恢复联网到首次上传完成 | 6.81 秒 |
| 新设备登录到恢复完成 | 6.52 秒 |
| 恢复阶段拉取 / 上传请求 | 18 / 0 次 |
| 新增 1 条到第二台设备同步完成 | 1.90 秒 |

| 冲突测试账号备份中的历史版本 | 4 个 |

## 复测方法

在仓库根执行 `npm run build:page`、`npm run build`、`npm run test:worker` 和 `npm run test:ui`。浏览器验收入口为 `node tools/check-cloud-sync.cjs`，使用本机的 `WRANGLER_JS`、`PLAYWRIGHT_PATH`、`CHROME_PATH` 和截图目录 `QA_OUTPUT`。脚本为每次运行创建新的本地数据库，结果写入该目录的 `metrics.json`。

## 上线前

收到上线确认后，在合并 `main` 前核对目标为生产库 `zwgcb-vault`（绑定 `VAULT`）。生产库已有 0001、0002 时，预期新增两份迁移：`0003_cloud_sync.sql` 和 `0004_history_quota.sql`。后者也支持已经执行 0003 并已有数据的库。

```powershell
npx wrangler d1 migrations list VAULT --remote
npx wrangler d1 migrations apply VAULT --remote
npx wrangler d1 migrations list VAULT --remote
npx wrangler d1 execute VAULT --remote --command "SELECT name FROM sqlite_schema WHERE name IN ('docs','history','docs_user_seq','docs_insert','docs_update','history_insert','history_delete') ORDER BY name"
```

核对没有待执行迁移，并确认最后一条查询返回两个表、一个索引、四个触发器。生产构建成功并核对版本后，手机验收重点是已有记录认领、同账号换设备恢复以及离线后再联网同步。
